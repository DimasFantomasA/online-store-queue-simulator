# Маппинг элементов СМО на сущности бизнес-домена

**Троян Дмитрий Максимович · 5130904/40101 · Вариант № 1**  
**Система:** центр обработки заказов интернет-магазина

> Markdown-представление предоставленного документа «Маппинг_Троян.docx». Содержание привязки к бизнес-домену сохранено.

| Элемент СМО | Сущность бизнес-домена | Назначение |
|---|---|---|
| Источник (ИБ, ИЗ1) | Клиент интернет-магазина | Формирует и отправляет заказы через сайт или мобильное приложение. Количество потенциальных клиентов не ограничено. Поступление заказов моделируется пуассоновским потоком. |
| Заявка | Заказ клиента | Содержит идентификаторы заказа и клиента, перечень товаров, количество, стоимость и время поступления. Представляет требование на обработку. |
| Буферная память (Д1ОЗ1) | Кольцевая очередь заказов | Хранит ожидающие заказы. Свободные места ищутся по кольцу: указатель последовательно проходит ячейки и после последней возвращается к первой. |
| Прибор (ПЗ2) | Сервер обработки заказов | Обрабатывает один заказ за раз. Время обработки — случайная величина с равномерным распределением. |
| Диспетчер постановки | Сервис приёма заказов | Принимает новый заказ; при отсутствии свободного сервера помещает в кольцевую очередь. При полном заполнении буфера запускает дисциплину Д1ОО1. |
| Дисциплина отказа (Д1ОО1) | Механизм вытеснения заказа | При полном заполнении очереди заказ под указателем удаляется, а на его место помещается новый. |
| Диспетчер выбора (Д2П1, Д2Б1) | Планировщик обработки заказов | Выбирает из очереди самую старую заявку (FIFO); свободный сервер выбирается по приоритету его номера. |
| Обслуживание (ПЗ2) | Обработка заказа сервером | Сервер проверяет заказ и наличие товаров, рассчитывает итоговые данные и формирует результат обработки. После завершения освобождается. |
| Выход из системы | Обработанный заказ | После завершения обслуживания заказ покидает систему, результат включается в статистику. |
| Автоматический режим (ОР2) | Модуль статистики и аналитики | Формирует графики зависимости вероятности отказа, среднего времени пребывания и загрузки серверов от параметров модели. |
| Пошаговый режим (ОД1) | Модуль мониторинга системы | Отображает календарь событий, кольцевую очередь, состояние серверов и текущие показатели на каждом шаге. |

Подробности запланированных программных классов: [первичные артефакты](primary-artifacts.md).
