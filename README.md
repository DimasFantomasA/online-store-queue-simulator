**Вариант:** № 1

## О проекте

Проект представляет собой дискретно-событийную имитационную модель центра обработки заказов интернет-магазина.

Система моделирует поступление заказов от клиентов, распределение заявок между вычислительными серверами, ожидание в кольцевом буфере, обработку заявок и возникновение отказов при переполнении буферной памяти.

Цель проекта — исследование характеристик системы массового обслуживания и определение эффективной конфигурации вычислительных ресурсов.

## Формула варианта СМО

`ИБ — ИЗ1 — ПЗ2 — Д1ОЗ1 — Д1ОО1 — Д2П1 — Д2Б1 — ОР2 — ОД1`

| Код | Описание |
|---|---|
| ИБ | Бесконечный источник |
| ИЗ1 | Пуассоновский поток заявок |
| ПЗ2 | Равномерный закон обслуживания |
| Д1ОЗ1 | Кольцевая организация буфера |
| Д1ОО1 | Отказ заявке под указателем |
| Д2П1 | Приоритет по номеру прибора |
| Д2Б1 | FIFO |
| ОР2 | Автоматический режим с графиками |
| ОД1 | Пошаговый режим с календарём событий |

Формулировки ОР2 и ОД1 приведены по заданию. По уточнению преподавателя пошаговый режим выводит состояние системы после каждого события. Календарь событий используется внутри модели.

## Архитектура системы

Основные компоненты:

- **OrderSource** — генерация заявок.
- **Order** — данные о заказе.
- **PlacementDispatcher** — постановка заявок.
- **CircularBuffer** — кольцевое хранение заявок.
- **SelectionDispatcher** — выбор заявки и прибора.
- **Server** — обслуживание заявки.
- **EventCalendar** — управление событиями.
- **StatisticsCollector** — сбор статистических данных.
- **SimulationEngine** — координация модели.

## Режимы моделирования

### Пошаговый режим (ОД1)

После каждого события программа показывает модельное время, состояние источников, содержимое кольцевого буфера, положение указателя, занятость приборов и текущую статистику.

### Автоматический режим (ОР2)

Отдельный автоматический режим запланирован.

## Запуск пошагового режима

1. Открыть корень репозитория в IntelliJ IDEA как Maven-проект и дождаться загрузки `pom.xml`.
2. Открыть [Main.java](src/main/java/Main.java) и запустить метод `main()`. Для ввода параметров через консоль оставить поле **Program arguments** пустым.
3. Ввести количество заказов, приборов и источников, размер буфера, границы времени обслуживания и интенсивность поступления для каждого источника. Нажать **Enter**, чтобы принять значение в квадратных скобках.
4. В поле **Seed** нажать **Enter** для случайного прогона или ввести целое число. Программа выведет выбранный seed. Одинаковые параметры и seed позволяют повторить прогон.

| Команда | Действие |
|---------|----------|
| **Enter** | Обработать одно событие и показать состояние системы. |
| `a` | Выполнить оставшиеся шаги с выводом состояния. |
| `q` | Остановить моделирование. |

После последнего поступления модель продолжает обслуживать заказы в буфере и на приборах. В конце программа выводит число поступивших и обработанных заказов, количество и долю отказов, а также статистику по источникам.
