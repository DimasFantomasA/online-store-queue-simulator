**Курсовой проект по имитационному моделированию систем массового обслуживания**

**Вариант:** № 1

## О проекте

Проект представляет собой дискретно-событийную имитационную модель центра обработки заказов интернет-магазина.

Система моделирует поступление заказов от клиентов, распределение заявок между вычислительными серверами, ожидание в кольцевом буфере, обработку заявок и возникновение отказов при переполнении буферной памяти.

Цель проекта — исследование характеристик системы массового обслуживания и определение эффективной конфигурации вычислительных ресурсов.

## Формула варианта СМО

`ИБ — ИЗ1 — ПЗ2 — Д1ОЗ1 — Д1ОО1 — Д2П1 — Д2Б1 — ОР2 — ОД1`

| Код | Описание |
|---|---|
| ИБ | Бесконечный источник |
| ИЗ1 | Пуассоновский поток заявок |
| ПЗ2 | Равномерный закон обслуживания |
| Д1ОЗ1 | Кольцевая организация буфера |
| Д1ОО1 | Отказ заявке под указателем |
| Д2П1 | Приоритет по номеру прибора |
| Д2Б1 | FIFO |
| ОР2 | Автоматический режим с графиками |
| ОД1 | Пошаговый режим с календарём событий |

## Архитектура системы

Основные компоненты:

- **OrderSource** — генерация заявок.
- **Order** — данные о заказе.
- **PlacementDispatcher** — постановка заявок.
- **CircularBuffer** — кольцевое хранение заявок.
- **SelectionDispatcher** — выбор заявки и прибора.
- **Server** — обслуживание заявки.
- **EventCalendar** — управление событиями.
- **StatisticsCollector** — сбор статистических данных.
- **SimulationEngine** — координация модели.

## Режимы моделирования

### Пошаговый режим (ОД1)
Отображение календаря событий, состояния серверов и буфера, положения указателей и статистики после каждого события.

### Автоматический режим (ОР2)
Проведение моделирования с различными параметрами, сбор статистики и построение графиков характеристик СМО.
